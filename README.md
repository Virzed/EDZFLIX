# Neroflix

This is the main repository for the Neroflix application built with Next.js.

## Features
- Authentication
- Admin Dashboard
- Neon Database Integration

## Setup
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables
4. Start the development server:
   ```bash
   npm run dev
   ```
